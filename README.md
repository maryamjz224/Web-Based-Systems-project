## About The Project

Kitab Store is a web-based online bookstore developed using HTML, CSS, 
JavaScript, PHP, and MySQL. The web allows customers to browse books by 
category(adult, children ), add them to a cart, and place orders, while the admin can 
manage books and track orders through a secure admin panel. The system also 
features session-based cart management and cookie-based purchase history to 
enhance the user experience.
